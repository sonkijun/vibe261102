## 1. 개요

### 1.1 배경
할 일 관리 앱은 많지만, 대부분 프로젝트·태그·마감일 등 기능이 많아 "오늘 무엇을 할지"에 집중하기 어렵다. 이 제품은 **오늘 하루에 해야 할 일만** 빠르게 적고, 체크하고, 진행률을 확인하는 데 집중한 가벼운 웹페이지다.

### 1.2 목표
- 3초 안에 할 일을 하나 추가할 수 있다.
- 오늘 할 일의 진행률을 한눈에 볼 수 있다.
- 설치·로그인 없이 브라우저만으로 쓸 수 있다.
- 새로고침하거나 브라우저를 다시 열어도 데이터가 남는다.

### 1.3 비목표 (이번 버전에서 하지 않는 것)
- 회원가입/로그인, 서버 동기화, 여러 기기 간 공유
- 프로젝트/폴더, 태그, 반복 일정, 알림(푸시)
- 협업(공유 리스트, 담당자 지정)

## 4. 기능 요구사항

### 4.1 할 일 추가 (P0)
- 상단 입력창에 텍스트 입력 후 **Enter** 또는 **추가 버튼**으로 등록한다.
- 앞뒤 공백을 제거하고, 빈 문자열은 추가하지 않는다 (입력창 흔들림 등으로 피드백).
- 최대 길이 200자. 초과 시 입력 제한.
- 새 항목은 목록 **맨 아래**에 추가된다.
- 추가 후 입력창은 비워지고 포커스가 유지된다.

### 4.2 완료 체크 (P0)
- 각 항목 왼쪽 체크박스를 클릭하면 완료/미완료가 토글된다.
- 완료 항목은 취소선 + 흐린 색으로 표시한다.
- 완료 시각(`completedAt`)을 기록한다.

### 4.3 수정 (P0)
- 항목 텍스트를 **더블클릭**(모바일: 길게 누르기 또는 편집 아이콘)하면 인라인 편집 모드가 된다.
- Enter 또는 포커스 아웃 → 저장, Esc → 취소.
- 편집 결과가 빈 문자열이면 삭제 확인을 띄운다.

### 4.4 삭제 (P0)
- 항목에 마우스를 올리면(모바일: 항상) 삭제 버튼(×)이 보인다.
- 삭제 후 화면 하단에 **"삭제됨 · 실행 취소"** 토스트를 5초간 표시한다. 실행 취소 시 원래 위치로 복구.

### 4.5 오늘 날짜 & 진행률 (P0)
- 헤더에 오늘 날짜를 표시한다. 예: `2026년 11월 2일 월요일`
- 진행률: `완료 수 / 전체 수`와 퍼센트, 진행 바를 표시한다.
- 전체가 0개면 진행 바 대신 빈 상태 문구를 보여준다.
- 모두 완료하면 축하 메시지(예: "오늘 할 일을 모두 끝냈어요! 🎉")를 표시한다.

### 4.6 데이터 저장 (P0)
- 브라우저 `localStorage`에 저장한다. 변경이 생길 때마다 즉시 저장.
- 데이터는 **날짜별**로 구분해 저장한다 (5장 데이터 모델 참고).
- 저장 실패(용량 초과, 시크릿 모드 등) 시 경고 배너를 띄우고 앱은 메모리 상태로 계속 동작한다.

### 4.7 필터 (P1)
- 탭: `전체` / `진행 중` / `완료`. 각 탭에 개수 표시.
- 선택한 필터는 새로고침 후에도 유지한다.

### 4.8 우선순위 (P1)
- 높음 / 보통(기본) / 낮음 3단계.
- 항목 왼쪽에 색상 점 또는 라벨로 표시 (높음=빨강, 보통=회색, 낮음=파랑).
- 정렬은 사용자가 정한 순서를 기본으로 하되, "우선순위순 정렬" 옵션을 제공한다.

### 4.9 순서 변경 (P1)
- 드래그 핸들(⋮⋮)로 순서 변경. 키보드 사용자는 항목 포커스 후 `Alt + ↑/↓`로 이동.

### 4.10 완료 항목 일괄 삭제 (P1)
- 하단 "완료 항목 지우기" 버튼. 완료 항목이 없으면 비활성화.
- 실행 전 확인 다이얼로그 표시.

### 4.11 어제 미완료 가져오기 (P2)
- 오늘 처음 접속했을 때 이전 날짜에 미완료 항목이 있으면 "어제 못 끝낸 N개를 가져올까요?" 배너 표시.
- [가져오기] → 오늘 목록에 복사, [닫기] → 오늘은 다시 묻지 않음.

### 4.12 다크 모드 (P2)
- 기본은 시스템 설정(`prefers-color-scheme`)을 따른다.
- 헤더의 토글로 라이트/다크 수동 전환 가능, 선택값 저장.

## 5. 데이터 모델

### 5.1 Todo 객체
```ts
type Priority = 'high' | 'medium' | 'low';

interface Todo {
  id: string;            // crypto.randomUUID()
  text: string;          // 1~200자
  completed: boolean;
  priority: Priority;    // 기본 'medium'
  order: number;         // 정렬 순서 (작을수록 위)
  createdAt: string;     // ISO 8601
  completedAt: string | null;
}
```

### 5.2 localStorage 구조
| Key | 값 | 설명 |
|---|---|---|
| `todo:v1:days` | `{ "2026-11-02": Todo[], ... }` | 날짜(로컬 기준 `YYYY-MM-DD`)별 할 일 |
| `todo:v1:settings` | `{ filter, theme, sortBy, lastCarryOverPrompt }` | 사용자 설정 |

- 키에 버전(`v1`)을 붙여 이후 스키마 변경 시 마이그레이션할 수 있게 한다.
- 30일이 지난 날짜 데이터는 접속 시 자동 정리한다 (용량 관리).
- "오늘" 판단은 사용자 로컬 시간대 기준. 자정을 넘겨 페이지를 열어둔 경우, 다음 사용자 동작 시 날짜 변경을 감지하고 새 날짜로 전환한다.

### 6.2 상태별 화면
| 상태 | 표시 |
|---|---|
| 빈 상태 (할 일 0개) | 일러스트/아이콘 + "오늘 할 일을 추가해 보세요" |
| 필터 결과 없음 | "완료한 항목이 없어요" 등 필터별 문구 |
| 전부 완료 | 진행 바 100% + 축하 메시지 |
| 저장 실패 | 상단 노란 배너: "저장 공간에 접근할 수 없어 새로고침 시 데이터가 사라질 수 있어요" |

### 6.3 반응형
| 구간 | 폭 | 레이아웃 |
|---|---|---|
| 모바일 | < 640px | 전체 폭, 좌우 여백 16px, 삭제 버튼 항상 노출 |
| 태블릿/데스크톱 | ≥ 640px | 가운데 정렬 카드, 최대 폭 560px |

### 6.4 디자인 가이드
- 폰트: 시스템 폰트 스택 (Pretendard 사용 가능 시 우선)
- 색상은 CSS 변수(토큰)로 정의하고 라이트/다크 두 벌 제공
- 체크·추가·삭제에 짧은 트랜지션(150~200ms), `prefers-reduced-motion` 시 애니메이션 끔
- 터치 영역 최소 44×44px

## 8. 기술 설계 (제안)

### 8.1 기술 스택
- **MVP 권장안: HTML + CSS + Vanilla JavaScript (빌드 도구 없음)**
  - 기능 범위가 작아 프레임워크 없이 충분하고, 파일을 브라우저로 바로 열어 확인 가능
- 확장 시 대안: Vite + React(또는 Svelte) + TypeScript

### 8.2 폴더 구조 (예정)
```
todolist/
├── prd.md          # 본 문서
├── index.html      # 마크업
├── styles.css      # 스타일 (디자인 토큰 포함)
└── js/
    ├── main.js     # 진입점, 이벤트 바인딩
    ├── store.js    # 상태 관리 + localStorage 저장/로드
    ├── render.js   # DOM 렌더링
    └── date.js     # 오늘 날짜 키, 날짜 포맷 유틸
```

### 8.3 아키텍처
```
사용자 이벤트 → main.js (핸들러)
              → store.js (상태 변경 → localStorage 저장)
              → render.js (상태 기반으로 목록/진행률 다시 그림)
```
- 단방향 흐름: 상태(state)가 단일 진실 공급원, 화면은 상태로부터만 그린다.
- store가 제공할 함수: `addTodo`, `toggleTodo`, `updateTodo`, `deleteTodo`, `restoreTodo`, `reorderTodo`, `clearCompleted`, `setFilter`, `getStats`

## 11. 수용 기준 (MVP 테스트 체크리스트)

- [ ] 텍스트 입력 후 Enter → 목록 맨 아래에 추가되고 입력창이 비워진다
- [ ] 공백만 입력하면 추가되지 않는다
- [ ] 체크박스 클릭 → 취소선 표시, 진행률이 즉시 갱신된다
- [ ] 더블클릭으로 수정, Esc로 취소된다
- [ ] 삭제 후 5초 안에 실행 취소하면 원래 위치로 돌아온다
- [ ] 새로고침 후에도 목록과 완료 상태가 그대로다
- [ ] 날짜가 바뀌면 새 날짜의 빈 목록이 보인다 (이전 날짜 데이터는 보존)
- [ ] `<script>alert(1)</script>` 입력 시 텍스트 그대로 보인다
- [ ] 키보드만으로 추가/체크/수정/삭제가 가능하다
- [ ] 375px 폭에서 가로 스크롤이 생기지 않는다
